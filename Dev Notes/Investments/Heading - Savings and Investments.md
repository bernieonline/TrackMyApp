Heading - Savings and Investments

Lets Call the App - MyBGAccounts

1.  "Month/Year"        Drop Down Year and Drop Down Box Month - Default on load should be current Year and Current Month unless the date is the early part of the month in which case default to the previous month. The aim is to complete the form on the last day of the month
2.  "Provider Name" - Text
    1.  Natwest Current (Savings)
    2.  Natwest Credit card (Savings)
    3.  Starling (Savings)
    4.  Close Bros ISA Mary (Investments)
    5.  Close Bros ISA Bernard (Investments)
    6.  Nationwide (Savings)
    7.  Marcus Bernard (Savings)
    8.  Vanguard Bernard (Investments)
    9.  Aviva ISA Mary (Investments)
    10. Aviva ISA Bernard (Investments)
    11. Aviva Pension Valuation (Pension)

&nbsp;       Each of the above will have a data entry field for a £ value 2 decimal places

&nbsp;       These records would be best displayed in a table, a slight colour shift in each row, alternating to make it easy to select the correct row visually

&nbsp;       I need the ability to add new Provider names from the list

&nbsp;       An edit button would be useful showing a checkbox against each item, uncheck would hide the entry

&nbsp;       When i view the previous months records only the providers showing a value greater or less than zero would be displayed as i page through them. I envisage a left and right button to step backwards and forwards through the records. I also need to display the comments and totals

I will also need the ability whilst in the Edit mode to adjust the Text labels

I also need the ability to change the numbers entered in case of errors

When the initial list of providers is set up I need the ability to define a label as either an Investment, Saving or Pension item

Below the data entry table I need rows for Totals

Row 1 Total of all savings and investments

Row 2 Total of All Savings only

Row 3 Total of all Investments

Row 4 Total of Pension Value

Row 5 Grand Total of all items

Each row should be colour coded for ease of reading

Below the Totals I need a comments box

It would also be useful to see a small table that shows the totals values for the previous 3 months

It would be useful to have a button that when selected would show a spreadsheet type display for the last year

As we tend not to draw money from investments it would be useful to display a growth rate +/- in the last year for investment items shown as a label to the right of the row. This isnt needed on every column when viewing previous records, only show it adjacent to the most recent record

it may also be useful to show the growth rate of the ftse 100 next to it. Again over the past year. This will allow a quick comparison between investment performance and a FTSE 100 tracker.

I plan to add the data for the  whole of the last year so other labels will be needed. Leeds ISA Mary, Leeds ISA Bernard, Santander Mary, Santander Bernard. Santander is a Savinds Account, Leeds is an investment account
